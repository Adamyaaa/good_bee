1. Executive Architecture Overview Core Ecosystem

The Good Bee Skincare Platform is an artisanal, cellular skincare commerce engine engineered for luxury brand storytelling and high-frequency operational control. Built on React 19 + Vite with an optimized Node.js / Express API, it delivers seamless patron journeys and granular administrative command over products, inventory, live CMS, and partner channels.

Patron Storefront (Public) Public Access

Ultra-responsive, aesthetic consumer boutique with dual-axis concern & category filters, interactive slide-over cart, GC/MS extraction lab research disclosures, and zero-fee Dynamic UPI QR + COD checkout.

Admin Console (Command Center) Authorized

High-frequency floating operational HUD with left-edge mouse-drag resizing, product creation & 1-click formulation cloning, live site CMS broadcasting, order lifecycle dispatch, and financial metrics.

3. Role 2: Super Admin Console — Complete Powers & Capabilities (Part I) Full Catalog Control

The Super Admin Console is the central nerve center of Good Bee. It provides complete operational autonomy to create, clone, price, modify, and monitor every aspect of the brand without developer assistance.

A. Operational Window Ergonomics & Mouse-Drag Resizability

Mouse-Draggable Left Edge Resizing Custom HUD

The admin console features a dedicated 6px left-edge grip handle. Admins can click and drag with their mouse to continuously resize the console width from 420px up to 96% of their monitor screen, with a real-time HUD badge display (e.g., ↔ 1040px).

1-Click Maximize / Restore & Double-Click Expand Ergonomics

A dedicated Maximize2 / Minimize2 icon toggles between comfortable side-docked review and true fullscreen command view. Double-clicking the resize handle toggles between maximum and default width instantly.

6. Architecture & Scalability Blueprint DevOps & Cloud

Frontend Layer: Vercel Edge Zero-Latency

Single Page Application served from Vercel's global CDN edges with sub-40ms response times and instant zero-downtime cache invalidation.

Backend Layer: Render Microservice REST API

Node.js Express API service configured via render.yaml blueprint. Supports JWT auth, order routing, and modular database scalability.

Resilient Dual-Sync Engine (Cold Start & Offline Immunity) Patented Reliability

Integrated via mockBackend.js: When deployed to production, the storefront automatically prioritizes the live Render API. If the backend is cold-starting or temporarily offline, the frontend seamlessly fails over to client-side localStorage state, guaranteeing that no customer ever encounters a blank screen or broken checkout.
