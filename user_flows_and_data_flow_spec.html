1. Architectural Framework: User Flow vs. Data Flow Dual-Layer Modeling

In enterprise commerce architectures, mapping user journeys requires a dual-layer abstraction. An action taken by one user in an isolated portal triggers cascading state mutations that propagate across other personas:

User Flow (UX & Intention Layer) Screen Action

Defines the human narrative: user objectives, entry views, decision paths, modal inputs, and instant UI feedback. Focuses on what the user perceives and touches across specialized suites.

Data Flow (System & State Layer) DFD & Mutation

Defines the machine reality: JSON payloads, REST API endpoints, validation logic, state machine transitions, and cross-boundary broadcasts that ripple into inventory and financial ledgers.

Quality Control & Quarantine State Transitions

State 1: Quarantined & Pending Review Quarantine Lock

Raw active is safely locked in the quarantine staging area. Cannot be added to retail or wholesale formulations until audited by certified brand chemists.

State 2: Clean Passed & Catalog Active Production Ready

Batch purity verified (>99% active ester index). Formulation is assigned master SKU and stock is routed directly into live storefront inventory.

B2B Financial Computation Logic

Wholesale Margin Formula Direct Margin

Wholesale Price = Retail MRP × (1 - (Commission Margin % ÷ 100))
Ensures contracted regional distributors receive guaranteed commercial margins on every batch.

GST & Commercial Invoicing Tax Compliant

Total Payable = Subtotal + (Subtotal × 0.18 GST)
Generates standardized tax invoices with HSN codes, company GSTIN, and Net-30 credit terms.
